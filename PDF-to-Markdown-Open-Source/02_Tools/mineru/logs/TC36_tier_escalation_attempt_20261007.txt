Conclusion: two independent, genuine blockers prevent any tier above "flash"
in this sandbox, both pre-existing and unrelated to this TC's fixture or
verdict:
  1. The local parse-server is disabled by default and cannot be enabled
     without the standard/basic/advanced-tier model weights (layout, OCR,
     formula, table ONNX models + a 1.2B GGUF model).
  2. Downloading those weights requires either huggingface.co or
     modelscope.cn -- both organization-egress-blocked from this sandbox
     (same policy that blocks every other model download attempted in this
     project: PaddleOCR-VL, MinerU's own earlier attempts, etc).
  3. --remote would call mineru.net, independently blocked by the same
     egress policy (confirmed earlier today: connect_rejected, 403).
"flash" (documented by MinerU's own CLI as "text-only preview") is the only
tier this installation can actually execute in this environment -- not a
choice made for convenience.
